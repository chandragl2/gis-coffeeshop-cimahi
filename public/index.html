Tentang Website

Sistem Informasi Geografis Coffeeshop Kota Cimahi

Website ini dibuat untuk menampilkan lokasi dan informasi coffeeshop yang tersebar di Kota Cimahi. Dengan menggunakan teknologi peta interaktif Mapbox GL JS, pengguna dapat dengan mudah menemukan coffeeshop favorit mereka berdasarkan lokasi geografis.

Fitur Utama:

  • 🗺️ Peta interaktif Kota Cimahi
  • 📍 Marker lokasi coffeeshop
  • 🔍 Fitur pencarian coffeeshop
  • ℹ️ Informasi detail setiap coffeeshop

Cara Menggunakan:

  1. Gunakan search bar di sebelah kiri untuk mencari coffeeshop
  2. Klik marker di peta untuk melihat detail coffeeshop
  3. Zoom in/out peta menggunakan scroll atau tombol zoom
  4. Drag peta untuk melihat area lain

Catatan: Data coffeeshop pada website ini adalah data dummy untuk keperluan tugas kuliah.
